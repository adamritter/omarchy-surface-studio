# Appearance presets

`ray-glass.json` contains Adam Ritter's tuned bar and panel appearance, including the experimental analytic ray-glass settings and button colors.

To apply it, first save any preview you want to keep and back up `~/.config/omarchy/surface-studio.json`. Copy `presets/ray-glass.json` to that path, then run `omarchy restart shell`. This replaces appearance settings only. Restore your backup and restart the shell to undo it. The preset enables runtime panel backdrop blur; see the root README for its compositor behavior.

Installing or updating the plugin does not automatically apply presets.
